# Confocal-Microscopy-Image-Quality-Dataset-240-FOV-
A benchmark of 2,640 multi-channel confocal fluorescence microscopy images from 240 fields of view (FOVs), where each FOV is an 11-plane Z-stack. Every image is annotated with a continuous quality score (0–100) and a five-level discrete grade (Abnormal / Poor / Fair / Good / Excellent), generated by fusing an expert-selected best-focal-plane prior, six objective quality indicators, and limited human quality control. Data are split at the FOV level into train / val / test (1,936 / 352 / 352). Designed for training and benchmarking no-reference (blind) image quality assessment on microscopy images.
